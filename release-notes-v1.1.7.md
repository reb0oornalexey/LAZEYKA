# LAZEYKA 1.1.7

## Автовыбор узла (новое)
- Блок «Автовыбор узла» — на главной вкладке INCY под кнопкой подключения и на вкладке ExitLag.
- «Автопереключение при сбое узла»: если узел рвёт соединения или DNS через него молчит, LAZEYKA сама проверяет запасные узлы настоящим запросом и переключается на рабочий. Выключено по умолчанию.
- Правила: какие узлы подписки можно выбирать автоматически — галочки по узлам и исключение по словам в названии (например, узлы с платным пакетом трафика). Вручную подключаться к ним можно как обычно.

## ExitLag
- Логика как задумано: включён — через VPN идут только приложения из списка; список пуст — туннель включён, но VPN не используется нигде.
- Telegram в списке ExitLag действительно идёт через VPN (вместе с TgWsProxy).
- Индикатор ExitLag в боковом меню и предупреждение на странице INCY.

## Оптимизатор маршрута (Faceit / CS2)
- Настоящий замер: по 20 игровых запросов (A2S) напрямую и через каждый быстрый узел подписки — пинг, джиттер, потери.
- Лучший узел по оценке «пинг + 2×джиттер + 5 мс за 1% потерь», подключение одной кнопкой.
- Новое: переключатель «Автоподключение к лучшему узлу» — по желанию, выключен по умолчанию; выбирает только из разрешённых узлов.
- Прямой замер при включённом TUN идёт мимо VPN — «прямое подключение» действительно прямое.
- Убраны выдуманные адреса «популярных серверов Faceit».

## Telegram
- Новое: «TgWsProxy через VPN INCY» — фото и видео Telegram идут через VPN, когда INCY подключён (в том числе в ExitLag).
- Новое: поле «Свой Cloudflare Worker» — официальное решение Flowseal, когда общие серверы Cloudflare отвечают 503 и медиа не грузится.

## INCY и ядра
- sing-box 1.14.1, Xray 26.9.9. Устаревшее скачанное ядро больше не перекрывает встроенное.
- Hysteria2-узлы, описанные провайдером для Xray, работают через Xray как есть.
- Переподключение быстрее — без 6-секундных пауз.
- Пинг узлов пересчитан честно: сетевая задержка до сервера (TCP, для Hysteria2/WireGuard — ICMP) идёт мимо TUN — раньше при включённом VPN у всех узлов было почти одинаковое число. Режим HTTP — время до первого байта ответа через сам узел, без времени запуска ядра; узлы формата Xray проверяются ядром Xray со всеми транспортами (раньше — ложные «нет ответа»).
- Адреса всех узлов подписки резолвятся напрямую, а не через текущий узел — замеры и переключение работают, даже когда текущий узел сломан.

## Логи
- Нет цветовых кодов, обрезанных строк и шума от каждого соединения.
- Одинаковые ошибки сворачиваются в одну строку.
- Понятные предупреждения: «сервер обрывает соединения — похоже на блокировку узла, смените узел» и «DNS через VPN не отвечает».
- Вывод Zapret и утилит Windows без «кракозябр».

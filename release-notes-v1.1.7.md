# LAZEYKA 1.1.7

## Оптимизатор маршрута ExitLag (Faceit / CS2)
- Теперь это настоящий замер, а не расчёт по карте. Вставьте `connect IP:порт` из комнаты матча — LAZEYKA отправит по 20 игровых запросов (A2S, как браузер серверов Steam) напрямую и через каждый быстрый узел подписки, тем же ядром, что и туннель.
- Для каждого узла: пинг, джиттер и потери. Лучший выбирается по оценке «пинг + 2×джиттер + 5 мс за 1% потерь»; подключение — одной кнопкой.
- Прогресс замера, предупреждения (включён полный VPN, блокировка UDP), честная пометка «оценка», если сервер не отвечает на игровые запросы.
- Убраны выдуманные «популярные локации Faceit» — у Faceit нет постоянных адресов серверов.

## Зачем это нужно

Сайты блокируют по-разному, и одного способа обхода на все случаи не
существует. VPN меняет IP, но режет скорость и ломает банки с Госуслугами.
Обход DPI скорость не трогает, но берёт не всё. Telegram тормозит по своим
причинам.

LAZEYKA собирает эти способы в одном месте, чтобы не ставить три программы
и не разбираться в каждой отдельно. Начинаете с самого безобидного, и
переходите к следующему, только если не хватило.

> **LAZEYKA не продаёт доступ к VPN и не имеет своих серверов.** Для раздела
> INCY нужна ссылка на подписку от стороннего провайдера — приложение
> только умеет с ней работать.

## С чего начать

1. **Включите Zapret** — вкладка «Zapret», большая кнопка. Проверьте нужный
   сайт. Не открылся — запустите «Автоподбор стратегии».
2. **Не хватило — добавьте VPN** — вкладка «INCY Proxy» → «Сервера» →
   вставьте ссылку на подписку или нажмите «Из буфера». Выберите сервер с
   зелёным пингом.
3. **Тормозит Telegram** — вкладка «Telegram», кнопка подключения сама
   пропишет настройки в мессенджере.

Включайте по одному способу за раз и проверяйте результат после каждого.
Если запустить всё сразу и что-то сломается, будет непонятно, что виновато.

## Что внутри

### Zapret — обход блокировок без VPN

Оборачивает `winws.exe` + драйвер `WinDivert`. Ничего никуда не
перенаправляет: слегка меняет вид ваших запросов, чтобы оборудование
провайдера не узнало заблокированный сайт. **IP остаётся вашим, скорость не
падает, задержка в играх не растёт.**

- **Стратегии** — готовые наборы под разных провайдеров. У каждого
  провайдера фильтрация своя, поэтому и рабочая стратегия разная.
- **Автоподбор** — приложение само перебирает стратегии и проверяет, открылся
  ли YouTube и Discord.
- **Автопилот** — продолжает следить за связью и переключает стратегию, если
  у провайдера что-то поменялось.
- **Списки хостов** — готовые наборы (Discord, YouTube, Telegram, Twitch,
  Cloudflare, Spotify) плюс полный авторский пак на 125 тысяч доменов.
  Добавление дописывает к вашему списку и не плодит дубли.
- **Конструктор стратегий** — ручная сборка аргументов `winws.exe`, если ни
  одна готовая не подошла.

### INCY — прокси и VPN на двух ядрах

| Ядро | Что умеет |
| --- | --- |
| `sing-box` | VLESS/Reality, Hysteria2 (QUIC), Trojan, Shadowsocks, режим TUN |
| `xray` | VLESS/VMess/Trojan/SS, фрагментация TLS ClientHello, шумовые пакеты, mux |

Топология выбирается автоматически под конкретный узел: одно ядро, второе,
или связка (sing-box держит TUN и передаёт трафик в Xray через локальный
мост). У каждого дефицитного ресурса — TUN-адаптера, порта, системного
прокси — ровно один владелец, так что ядра не конфликтуют.

- **Три режима** — TUN (весь компьютер), системный прокси (браузеры и
  программы, читающие настройки Windows), только прокси (локальный порт,
  который вы указываете сами).
- **Подписки** — вставка ссылки или кнопка «Из буфера», автообновление по
  расписанию, уведомление об истечении. Конфигурация провайдера
  воспроизводится дословно, поэтому работают и экзотические транспорты
  (ws, grpc, httpupgrade, xhttp), которые обычно теряются при разборе.
- **Профили маршрутизации** — «Раздельно» (российские сайты напрямую),
  «Глобально», «Напрямую», плюс свои сохранённые профили.
- **Гео-списки** — 20 категорий с отдельными переключателями: Steam, Apple и
  Microsoft ходят напрямую, YouTube и Telegram через туннель, реклама
  блокируется. Любую строчку можно выключить.
- **Свои правила** — домен или подсеть → напрямую / туннель / блок. Ваши
  правила главнее всех готовых списков.
- **Пинг** — четыре протокола (TCP-рукопожатие, настоящий HTTP-запрос через
  сервер) и четыре способа отображения.
- **Статистика** — реальные байты через Clash API ядра, история за 14 дней,
  недельный график.
- **Резервная копия** — подписка, серверы, правила и настройки в один файл.
  Восстановление показывает содержимое до применения.

### Telegram WS-прокси

Локальный MTProto-over-WebSocket релей — отдельный прокси только для
Telegram. Ускоряет загрузку медиа и чинит звонки, остальной интернет не
трогает. Подключение в один клик (ссылка доставляется прямо в запущенный TG)
и QR-код для телефона. Работает с Telegram Desktop и форками: AyuGram,
64Gram, Forkgram, Nekogram, Kotatogram, Unigram.

### Остальное

- **Шифрованный DNS (DoH/DoT)** — Cloudflare, Google, Quad9, Xbox DNS с
  замером задержки. Иногда одного этого достаточно, чтобы сайт открылся.
- **Игровой режим** — замечает запуск игры (Dota 2, CS2, Valorant, Apex,
  PUBG) и выводит её трафик из-под обработки, чтобы обход не добавлял пинг.
- **Ссылки-команды** — схема `lazeyka://`: `connect`, `disconnect`, `toggle`,
  `import/{base64}`, `routing/add/{base64}`. Можно сделать ярлык на рабочем
  столе, который включает VPN двойным щелчком.
- **Автообновление** — само приложение, бинарники TgWsProxy и Zapret, ядра
  `sing-box`/`xray` и гео-базы RoscomVPN. Патч-версии ядер ставятся молча,
  minor/major только сообщаются: sing-box меняет схему конфига между
  минорами, и неконтролируемый скачок может уронить туннель. Каждый
  кандидат проверяется через `sing-box check` / `xray -test` **до** подмены
  рабочего файла, старый остаётся как `.bak`.
- **Трей и автозапуск** — сворачивание в трей, запуск вместе с Windows через
  scheduled task, опция полностью убрать иконку с панели задач.
- **Портативный режим** — положите рядом с `.exe` файл-маркер `PORTABLE`, и
  приложение будет хранить данные в локальной папке `data/`.

## Приватность

Настройки и логи лежат только на вашем компьютере, в
`%APPDATA%\lazeyka` (или в `data/` рядом с `.exe` в портативном режиме).
Приложение ходит в сеть за обновлениями (GitHub), за гео-базами и к серверу
вашей подписки — больше никуда. Телеметрии нет.

При первом запуске генерируется случайный секрет для Telegram-прокси и
логин/пароль для локального прокси — на двух установках они не совпадают.
В резервную копию эти данные не попадают.

## Требования

- Windows 10 или 11 (x64)
- **Права администратора** — обязательны: Zapret работает на уровне сетевого
  драйвера, а режим TUN создаёт виртуальный сетевой адаптер.

## Разработка

```bash
pnpm install
pnpm dev
```

Dev-режим использует отдельную папку `%APPDATA%\lazeyka-dev`, так что
эксперименты не затрагивают рабочий конфиг.

```bash
pnpm typecheck    # tsc для main и renderer
pnpm lint
pnpm build:win    # из консоли с правами администратора
```

Сборка Windows-инсталлятора возможна только на Windows: используется NSIS,
и `node_modules` содержит Windows-сборку Electron.

Про выпуск релизов и контракт автообновления — [RELEASING.md](./RELEASING.md).
Разбор архитектуры и всех модулей — [docs/ARCHITECTURE.md](./docs/ARCHITECTURE.md).

### Стек

- **Electron 37** + TypeScript, сборка через `electron-vite`
- **React 19 + Vite + Tailwind CSS v4**, shadcn/ui + Radix + Lucide
- **Zustand** для состояния, типизированный IPC-мост main↔renderer
- **electron-builder + NSIS**, установщик perMachine с правами админа
- **PyInstaller** для пересборки headless TgWsProxy CLI

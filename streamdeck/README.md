# Плагин Stream Deck для LAZEYKA

Кнопки Stream Deck, которые управляют LAZEYKA. Плагин ничего не делает сам: по нажатию он просит Stream Deck открыть ссылку `lazeyka://…`, а программа выполняет команду. LAZEYKA должна быть установлена (так Windows и macOS знают, какая программа открывает `lazeyka://`). Если программа закрыта, ссылка её запустит.

Нужен Stream Deck 6.4 или новее.

## Действия

| Кнопка | Настройка | Ссылка |
| --- | --- | --- |
| VPN (INCY) | включить / выключить / переключить | `lazeyka://connect`, `lazeyka://disconnect`, `lazeyka://toggle` |
| Zapret | то же | `lazeyka://zapret/on`, `off`, `toggle` |
| Telegram-прокси | то же | `lazeyka://telegram/on`, `off`, `toggle` |
| ExitLag | то же | `lazeyka://exitlag/on`, `off`, `toggle` |
| Сценарий | идентификатор сценария | `lazeyka://scenario/<id>` |

Кроме кнопок эти же ссылки можно открывать из ярлыка или командной строки. Ещё есть `lazeyka://mini` — показать или скрыть мини-окно.

Ссылки защищены подписью. Ссылки, которые выдаёт программа («Стример → Кнопки для стрим-пульта»), и плагин, установленный кнопкой «Установить плагин», содержат код этой установки (`lazeyka://zapret/off?k=…`): такие команды выполняются сразу, без открытия главного окна. Ссылку без кода (например, открытую веб-страницей) программа выполнит только после подтверждения «Выполнить?». Без подтверждения работает только `lazeyka://mini`.

Плагин, собранный вручную из репозитория (`plugin/codes.js` пустой), работает, но каждое нажатие спрашивает подтверждение. Кнопка «Обновить ссылки» выпускает новый код: старые ссылки и плагин начинают спрашивать подтверждение, плагин нужно переустановить из программы.

## Установка

Проще всего из программы: «Настройки → Stream Deck → Установить плагин». Программа открывает файл плагина, приложение Stream Deck предложит его установить. Кнопка «Показать файл в папке» открывает папку с файлом, если автоматически не получилось. Там же лежат готовые ссылки `lazeyka://…` для тех, у кого нет Stream Deck.

Вручную:

1. Соберите архив: `node scripts/pack-streamdeck.mjs`. Файл появится в `streamdeck/dist/com.reb0oorn.lazeyka.streamDeckPlugin`.
   Файл `.streamDeckPlugin` — это обычный zip-архив каталога `com.reb0oorn.lazeyka.sdPlugin`.
2. Дважды щёлкните по файлу. Stream Deck предложит установить плагин.
3. В списке действий справа найдите раздел «LAZEYKA» и перетащите нужные кнопки на панель.

Если нужной команды нет под рукой (нет Node.js), архив можно собрать в PowerShell. Команда выполняется из корня репозитория:

```powershell
Compress-Archive -Path streamdeck\com.reb0oorn.lazeyka.sdPlugin -DestinationPath streamdeck\dist\lazeyka.zip -Force
Rename-Item streamdeck\dist\lazeyka.zip com.reb0oorn.lazeyka.streamDeckPlugin
```

Если Stream Deck не принимает такой архив, пользуйтесь скриптом на Node.js: он пишет пути с прямыми слэшами, а `Compress-Archive` в Windows PowerShell 5 пишет с обратными.

Без упаковки можно положить каталог `com.reb0oorn.lazeyka.sdPlugin` в папку плагинов и перезапустить Stream Deck:

- Windows: `%APPDATA%\Elgato\StreamDeck\Plugins\`
- macOS: `~/Library/Application Support/com.elgato.StreamDeck/Plugins/`

## Сценарии

Кнопке «Сценарий» нужен идентификатор. Он лежит в файле `scenarios.json` в каталоге данных LAZEYKA (поле `id`, вид `sc-lx3k9`).

## Значки

Значки (однотонный квадрат с буквой) рисует скрипт `node scripts/gen-streamdeck-icons.mjs`. Замените их своими PNG с теми же именами и размерами: 20 и 40 пикселей (список действий), 72 и 144 (кнопка), 256 и 512 (значок плагина), 28 и 56 (значок раздела).

## Чего нет

Пинга на кнопке нет: для него LAZEYKA должна отдавать данные плагину через локальный сервер.

# LAZEYKA — счётчик «сейчас онлайн»

Отдельный Cloudflare Worker, который считает, сколько копий LAZEYKA запущено
прямо сейчас. Разворачивается в **отдельном бесплатном аккаунте** Cloudflare —
не в том, где Worker для Telegram (у них общий лимит запросов на аккаунт).

## Развернуть (один раз)

```
cd C:\LAZEYKA\cloudflare\online-counter
npx wrangler login
npx wrangler deploy
```

`wrangler login` откроет браузер — войдите в НОВЫЙ аккаунт Cloudflare.
После `deploy` в конце будет адрес вида
`https://lazeyka-online.<имя>.workers.dev` — его и нужно вписать в программу
(`ONLINE_COUNTER_URL` в `src/main/core/online-counter.ts`).

Проверка: откройте `https://lazeyka-online.<имя>.workers.dev/online` — должно
быть `{"online":0}`.

## Безопасность

- В программе нет никаких ключей — только публичный адрес.
- Хранится только время последней отметки анонимного ID, в памяти.
- IP используется только на окно в 7 минут для защиты от накрутки и не сохраняется.
- Бесплатный тариф: 100 000 запросов в сутки. Отметка раз в 5 минут = 288
  запросов в сутки на человека, то есть примерно 340 человек онлайн одновременно.
  Если упрётесь — увеличьте интервал в программе или включите платный тариф
  Workers ($5/мес, 10 млн запросов).

# LAZEYKA — счётчик «сейчас онлайн»

Отдельный Cloudflare Worker, который считает, сколько копий LAZEYKA запущено
прямо сейчас. Разворачивается в **отдельном бесплатном аккаунте** Cloudflare —
не в том, где Worker для Telegram (у них общий лимит запросов на аккаунт).

## Развернуть (один раз)

```
cd C:\LAZEYKA\cloudflare\online-counter
npx wrangler login
npx wrangler deploy
```

`wrangler login` откроет браузер — войдите в НОВЫЙ аккаунт Cloudflare.
После `deploy` в конце будет адрес вида
`https://lazeyka-online.<имя>.workers.dev` — его и нужно вписать в программу
(`ONLINE_COUNTER_URL` в `src/main/core/online-counter.ts`).

Проверка: откройте `https://lazeyka-online.<имя>.workers.dev/online` — должно
быть `{"online":0}`.

## Статистика пользователей

Кроме «онлайн» Worker хранит постоянную таблицу анонимных ID (`installs`: первая
и последняя отметка, не чистится) и рекорд онлайна. `GET /stats` и ответ `/ping`
возвращают `{ online, installs, active24h, active7d, active30d, peakOnline }`.
Старые версии программы читают только `online` — они продолжают работать.
Новые таблицы создаются сами (`CREATE TABLE IF NOT EXISTS`), миграция не нужна;
уже известные ID переносятся при первом запуске новой версии Worker. После
изменения нужно снова выполнить `npx wrangler deploy`.

## Номер установки и владелец

Каждой новой установке при первой отметке выдаётся порядковый номер `num`
(2, 3, …; старые записи пронумерованы по дате первой отметки). `/ping` возвращает
`num` вызвавшего — программа показывает его как «Ваш номер: #N». ID наружу не
отдаются. Номер 1 никогда не получит никто, кроме владельца.

Чтобы закрепить номер 1 за собой, один раз задайте секрет `OWNER_ID` — ваш
анонимный ID (файл `online-id` в папке данных программы). В `cloudflare/online-counter`:

```
type %APPDATA%\lazeyka\online-id | npx wrangler secret put OWNER_ID
npx wrangler deploy
```

Если вы уже были зарегистрированы под другим номером, при следующей отметке вы
переедете на 1 (если она свободна).

## Безопасность

- В программе нет никаких ключей — только публичный адрес.
- Хранятся только анонимный ID и время его первой/последней отметки (SQLite Durable Object).
- IP используется только на окно в 7 минут для защиты от накрутки и не сохраняется.
- Бесплатный тариф: 100 000 запросов в сутки. Отметка раз в 5 минут = 288
  запросов в сутки на человека, то есть примерно 340 человек онлайн одновременно.
  Если упрётесь — увеличьте интервал в программе или включите платный тариф
  Workers ($5/мес, 10 млн запросов).

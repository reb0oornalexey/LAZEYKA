# LAZEYKA 1.1.5

## Исправлено
- **ExitLag снова работает.** Приложения с заглавными буквами в имени (`Discord.exe`, `Telegram.exe`, `VALORANT-Win64-Shipping.exe`) раньше не попадали в туннель: ядро сравнивает имена с учётом регистра, а список приводился к нижнему. Теперь сравнение без учёта регистра.
- ExitLag всегда поднимает TUN (в режимах «Системный прокси» / «Только прокси» трафик игр не перехватывался).
- ExitLag с пустым списком больше не отправляет весь трафик мимо VPN — туннель работает как обычный VPN, в логе есть подсказка.
- На странице INCY видно, что включён ExitLag, и есть кнопка «Весь трафик через VPN».
- Индикатор ExitLag в боковом меню (горит, когда ядро подтвердило сессию ExitLag).
- Изменения ExitLag и маршрутизации применяются сразу — туннель переподключается сам.
- Настройки больше не затираются между вкладками INCY и ExitLag.
- Свои правила маршрутизации снова важнее встроенного обхода РФ.
- Домены `.рф` и кириллические исключения теперь действительно идут напрямую (punycode).
- Локальная сеть (роутер, NAS, принтер, 10.x/172.16.x) всегда напрямую.
- IPv6 больше не утекает мимо туннеля.
- Меньше нагрузки: ядро пишет лог уровня warn, лог больше не читает файл настроек на каждую строку.
- Шумовые «ошибки» `wsasend … aborted` (закрытие соединения самим приложением) больше не помечаются как ошибки.
- WireGuard-узлы в формате Xray работают; для WARP передаются reserved-байты.

## Telegram (TgWsProxy)
- Возвращены адреса дата-центров по умолчанию из Flowseal (`149.154.167.220`), DC 203 (видео и медиа) идёт через тот же WebSocket-фронтенд.
- TgWsProxy работает в консольном режиме Flowseal — без иконки в трее и без окон.
- Обновление TgWsProxy проверяется перед установкой и откатывается при ошибке.
- Секрет прокси не попадает в логи и диагностический отчёт.

## Прочее
- Дочерние процессы завершаются по своим PID: LAZEYKA больше не закрывает sing-box/xray других программ (Hiddify, v2rayN и т.п.); процессы, оставшиеся после сбоя, завершаются при следующем запуске.
- Замер пинга до игровых серверов: местоположение узла по GeoIP, расчётные значения помечены «≈ оценка»; без мелькающего окна ping.
- QR-сканер проверяет все мониторы в полном разрешении.
